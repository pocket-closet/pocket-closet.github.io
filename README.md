# Pocket Closet

A free, private closet for your Infinity Nikki outfits — save as many looks as you like, beyond
the game's 100-slot lookbook.

- Drop in the QR screenshots you share from the game: Pocket Closet reads the code and keeps the
  picture. Copy the code back into the game with one tap.
- Names, notes, the game's Style and labels, your own labels, colors, collections.
- Works offline and can be installed on your phone's home screen.
- **Private:** no accounts, nothing is uploaded. Your closet lives only in your own browser.
  Use Settings → Backup to keep a copy or move it to another device.

*Unofficial fan tool. Not affiliated with Infinity Nikki or its makers.*
